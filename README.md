# Vastu Griha Analyzer APK
GitHub-ready Android project.

Features:
- 8-direction traditional Vastu assessment
- 9x9 / 81-pada Mandala visualization
- Brahmasthan highlight
- Main entrance check
- Room Planner for master bedroom, kitchen, puja, living, toilet, staircase, study, etc.
- Local rules: no external Vastu API required
- GitHub Actions builds a debug APK

## Build
Upload this project to GitHub, then open Actions -> Build Vastu APK. Download the `vastu-griha-analyzer-apk` artifact.

Note: Vastu rules vary between traditions. This is a traditional guidance tool, not a structural or building-code calculator.
